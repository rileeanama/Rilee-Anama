# FX Hedging

This capability demonstrates how to evaluate a foreign-currency receivable and compare different hedging strategies.

For this project, the company expects to receive EUR 4,700,000 in 91 days from a Spanish customer. The analysis compares a forward hedge, a money-market hedge, and option-based strategies.

## Files in This Folder

- `README.md` — explains the purpose of the FX hedging capability
- `spec.md` — Stage 2 model specification that defines the workbook before it is built
- `model.xlsx` — will be added in Stage 3 and used for the hedge analysis

## What This Capability Shows

This project demonstrates the ability to:

- identify and explain foreign exchange exposure
- compare multiple hedge strategies
- design a financial model before building it
- use named ranges and validation checks
- evaluate how exchange-rate changes affect USD proceeds
- document assumptions, formulas, and model logic clearly
